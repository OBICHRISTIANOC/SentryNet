Pipeline

How a scan actually works

From pasted link to verdict, every request moves through the same four stages.

01

Submit the URL

Paste a link into the scanner or send it to the REST API. No login or software install required.

02

Extract features

The backend parses the URL's structure — length, subdomains, symbols, HTTPS usage, host details — into a feature vector.

03

Classify with ML

The Random Forest model, trained on labelled phishing and legitimate URLs, scores the vector in milliseconds.

04

Return the verdict

You get a safe / suspicious / malicious result with a confidence score and the signals behind it.
