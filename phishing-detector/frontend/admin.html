Getting started

What each section of this panel controls.

  • Manage Users — create or remove administrator accounts.
  • Scan History — every URL scanned through the live API, with delete controls.
  • Trusted Domains — the brand registry used for impersonation detection.
  • Dataset & Model — upload a labelled CSV and trigger a model retrain.
  • System Logs — authentication events, rejected input, and errors.
  • Reports — export the full scan history as a CSV report.
